# makefun-absurd-clause

One line, 200 characters at most: an absurd clause hidden deep inside a terms-of-service agreement. A judge model reads the clauses in pairs and the funniest one takes the reward.

## Entry

> By using this service you agree that your left sock becomes company property on Tuesdays and may be repossessed without notice.

## Run

```sh
node main.ts
```

The program writes exactly one original English sentence to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
